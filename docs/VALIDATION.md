# 0.1.0 发布验收

日期：2026-10-28（Asia/Tokyo）。

- 16项 Node 隔离测试通过：协议压缩/非法帧、批次锁定、安静期、过期租约、重复回复、不可中断播放、只读状态、控制鉴权、文字与笔记不播音、SSE与模拟TTS/播放回执。
- 实际打开互动台，走通「演示弹幕→只回文字→领取→提交→思路更新」；两个框在独立画面源显示。
- 本机40次 HTTP 注入到 SSE reader：p50约1.77ms，p95约4.45ms，最大约11.63ms。**不包含**真实B站公网、模型、TTS、DOM绘制或音频设备。
- 用作者本机已有登录做过一次**只接收的真实 B站 WebSocket 鉴权**，成功；连接建立约1.21秒。这不是每条弹幕的延迟，不是朋友的账号验收，也未发送任何弹幕。
- Qwen适配器提供源码与官方接口说明，未在此包验收中下载模型、运行GPU推理或播放人声。模拟TTS测试不能证明真实音色和合成速度。
- 发布文件检查排除所有角色图片、模型、声音、Cookie/API key、运行数据及原直播记录。

每个使用者仍需在自己的环境完成：真实弹幕一条、自己的模型回答、自己的TTS、单播放器、直播收音回放。自动互动前先确认公开话题规则；本包不代替语义审核。
